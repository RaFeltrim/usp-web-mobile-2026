## 📖 Estrutura Conceitual do Módulo

### 1. Evolução e Arquitetura da Web
- Da Web 1.0 estática (hipertexto e links simples) à Web 2.0 interativa (AJAX, SPAs, redes sociais) e Web 3.0/Moderna (PWA, Jamstack, edge computing).
- O papel do W3C (*World Wide Web Consortium*) e a padronização dos ecossistemas abertos.

### 2. Protocolos e Infraestrutura
- Protocolos da pilha de aplicação: HTTP/1.1, HTTP/2 e HTTP/3 (QUIC sobre UDP).
- Métodos idempotentes vs. não-idempotentes (GET, POST, PUT, DELETE, PATCH, OPTIONS).
- Segurança na camada de transporte (TLS/HTTPS) e cabeçalhos de proteção (CSP, CORS, HSTS).

### 3. Ferramental do Desenvolvedor (DevTools)
- Inspecionando elementos DOM e CSS Box Model.
- Análise de requisições de rede (*Network tab*): latência, TTFB, compressão Gzip/Brotli e caching HTTP.
- Execução, breakpoints e depuração JavaScript via Console e Sources.
